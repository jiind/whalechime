# 구현과 검증 기록

2026-10-30 기준으로 로컬 전용 환경에서 확인했다. 외부 사용자나 조직의 메신저로 알림을 보내지 않았다.

## 요구사항별 확인

| 범위 | 구현 | 검증 근거 |

| 개인 수신처 | 본인 추가·수정·삭제·활성화·테스트 발송 | 브라우저 회귀 테스트, 타 사용자 수정·삭제·테스트 발송 거부 확인 |

## 실행한 검증

- 루트 Go 모듈: `go test -race -count=1 ./...`에 전용 PostgreSQL, 실제 Docker, 로컬 Registry, 실제 로그 컨테이너를 지정해 통과.
- 트레이 모듈: `WHALECHIME_NATIVE_TRAY_TEST=1 dbus-run-session -- go test -race -count=1 ./...` 통과.
- 루트·트레이 모듈 각각 `go vet ./...` 통과.
- `GOOS=windows CGO_ENABLED=0 go build` 트레이 교차 빌드 통과.
- `npm run test:ui`: 개인 항목·수신처, 관리자 팀 연결·일반 사용자, 모바일 진입·로그아웃 총 3개 통과.
- 중앙 서버 Compose `up --build -d --wait`와 에이전트 Compose `run --build --rm agent -check` 통과.
- `git diff --check`, Go 서식, JavaScript 구문, Bash 구문 확인.

실제 Docker 통합 테스트의 추가 환경변수는 `WHALECHIME_TEST_DOCKER=1`, `WHALECHIME_TEST_REGISTRY=로컬주소:포트`다. 로컬에 `alpine:3.22` 이미지가 있어야 하며 테스트는 자신이 만든 컨테이너와 이미지 태그만 정리한다. 실제 로그 테스트의 컨테이너 환경변수는 [운영 안내](operations.md)를 따른다.

브라우저 로그 미리보기는 매 줄에 **미리보기**라고 표시한 합성 데이터를 사용했다. 실제 Docker 출력 검증과 구분한다. 네이티브 메뉴 검증은 실제 OS의 DBus 메뉴 프로토콜을 사용하지만 특정 사용자의 데스크톱에서 마우스를 우클릭해 확인한 것은 아니다.

## 외부 환경에서 확인할 항목

- 각 사용자가 등록하는 실제 SMTP·메신저 계정의 접속·권한·최종 배달은 해당 수신처의 테스트 발송으로 확인한다.
- Windows 트레이는 교차 빌드까지 확인했으며 Windows/macOS 사용자 데스크톱에서의 실제 클릭·렌더링은 이 Linux 검증에 포함하지 않았다.
- Rootless Docker 분기는 실제 Rootless 데몬에서의 실행 검증에 포함하지 않았다.
- GitHub Actions 구성은 추가했으며 원격 실행 결과는 아직 없다.

현재 수집 범위, 단일 중앙 서버 운영, Docker 과거 이벤트 제한 등 제품 동작의 경계는 [README](../README.md)와 [운영 안내](operations.md)에 기록했다.
